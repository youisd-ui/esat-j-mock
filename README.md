# ESAT-J YEAR 3 模試

東京都の中学校英語スピーキングテスト（ESAT-J YEAR 3）と同じ形式で練習できるスピーキング模試です（全5回）。

- ポータル: https://youisd-ui.github.io/esat-j-mock/
- 各回: `mock1/` 〜 `mock5/`
- パソコンの Google Chrome で開き、マイクの使用を許可してください。
- 録音と文字起こしはブラウザの中だけで処理され、サーバーには送られません。
- 問題はこの模試のためのオリジナルです。採点は公式の採点基準を参考にした目安です。

## 問題の作り直し
各回のページは `src/` から生成しています。問題は `src/rounds.js`、イラスト部品は `src/lib.js` にあります。
編集したら `python3 src/build.py` を実行してください。
